# Clementine-XT for Schwung (Ableton Move)

A first cut of the Schwung version. It reuses the whole engine in `../src` (patch format, oscillators, filters, effects, modulation,
banks) behind Schwung's plugin API v2, and describes the controls to Schwung's generic knob grid. Nothing here has run on a Move yet; what
has run is the host simulation below and the Force build of the same engine.

## What is here
| File | |
|---|---|
| `src/schwung_plugin.c` | `plugin_api_v2` around the engine: worker thread for the slow parts, parameter and MIDI plumbing, the preset and bank pickers |
| `module.json`, `src/schwung_meta.h` | generated by `tools/gen_schwung.py` from `vst/params.json`: `chain_params` (202 controls with ranges and option lists) and the `ui_hierarchy` (37 pages) |
| `scripts/test.sh` | host simulation under ASan/UBSan, no Move needed: `src/schwung_plugin.c` + the engine + `test/host_sim.c` |
| `scripts/build.sh` | aarch64 cross build in Docker, packs `build/schwung/clementine-xt-module.tar.gz` (`clementine-xt/{module.json,dsp.so}`) |

`../src/vendor/schwung/plugin_api_v1.h` is Schwung's API header (MIT) and `../src/vendor/mpc-vst-plugins/engine.h` is the engine interface
both frontends use; both are listed in `../src/VENDORED.md`.

## How it works
- **Threading.** Schwung runs every module entry point on the SPI audio callback, where file access, allocation and blocking are forbidden. The
  engine scans the `ROMS` folder, reads the ROM and builds its tables when it is created, and reads a `.syx` file when a bank is loaded. So
  `create_instance` only starts a worker thread (demoted to SCHED_OTHER on cores 0-2 as the API header requires), the worker creates the engine
  and publishes it, and until then the module renders silence. A bank change is queued to the same worker. `destroy_instance` just sets a flag; the
  worker frees everything.
- **Pages.** The root page is the sound picker (`preset` 0-255, name from the engine) with the four Play knobs, filter cutoff and resonance,
  volume and effect parameter 1 on the eight knobs. From it: **Bank** (a list of `.syx` banks), **Play Assign** (which parameter each Play knob
  drives), then oscillators, waves, mixer, filters, envelopes, LFOs, glide, voices, effect, arpeggiator, the matrix (amounts, sources and
  destinations, eight slots a page) and the modifiers. Enum controls open a list; a two-option enum flips on click.
- **Sounds and ROMs.** User files live in `/data/UserData/schwung/clementine-xt/ROMS/` (override with the `CLEMENTINE_XT_DATA` environment
  variable), outside the module folder so module updates keep them. Copy your own Microwave II ROM dump (two 128 KB chips or one 256 KB
  image) and any `.syx` banks there. Without a ROM the 12 built-in sounds play on an open set of wave tables. The module ships none of
  them.
- **Tempo.** Each block asks Schwung's `get_bpm` and hands a changed tempo to the engine, so the arpeggiator's Tempo 0 (extern) follows the host.
- **Output.** The engine's 44.1 kHz stereo `int16` in 128-frame blocks is exactly what Schwung expects.

## Build and test
```
schwung/scripts/test.sh     # regenerates module.json, then the host simulation (x86, ASan)
schwung/scripts/build.sh    # aarch64 module tarball in build/schwung/
```

## To do before a release
- Run it on a Move: load time, CPU (the Force runs 8 voices at 15 % of a core; the Move's cores are different), the knob pages, the bank picker.
- Check the ui_hierarchy with Schwung's own validator (`tools/param-pages/validate.mjs`, needs Node) and the preview tools.
- Moving to its own repo: copy `schwung/`, `src/` (engine plus `src/vendor`), `tools/gen_schwung.py`, `tools/gen_patch.py`, `tools/sdata_lists.json`, `vst/params.json`,
  the GPL `LICENSE` and the legal notes in the main README (no ROM, no Waldorf names in the module id or name), then adjust the paths in the two scripts.
  Add the catalog files (`release.json`, a catalog entry) the way other Schwung modules do.
- Known gaps: sound names only for the current sound (the preset
  page shows the number and name of the one you select), the engine's sound save/state key is not used (Schwung keeps the control values).
